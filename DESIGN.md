# RefurbTrack design direction

Source: the supplied RefurbTrack infographic and concept paper.

Reading this as a mobile workshop ledger for the owner and technicians of AJ Cellphone Repair Shop and Accessories, using the supplied navy and teal identity. ENERGY 2 / RHYTHM 1 / MOTION 1.

- Navy headings identify the app and financial totals; deep teal marks the primary action. The light background supports reading cost records in a working repair shop.
- System typography follows Android text scaling and keeps intake forms readable. Tabular financial values align amounts for comparison.
- A single-column phone layout keeps labels above inputs. Wider screens use a centered readable workspace rather than stretching forms.
- Record rows act like workshop tickets: job type, device, status, and cost. Financial summaries carry more weight than secondary notes.
- Minimum 48-point controls, visible keyboard focus, text status labels, safe-area spacing, and keyboard-aware forms support actual use.
- Motion is limited to native navigation and press feedback. No decorative animation or generic stock imagery.
- The app uses the existing project icon until an approved standalone brand asset is supplied. The infographic is retained as source material, not recreated.

The user authorized applying all five Anti Slop skills during implementation. Navigation follows the requested records, history, dashboard, and staff authentication features.
